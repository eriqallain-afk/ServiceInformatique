# Services informatiques — Éric Allain

Site statique (HTML/CSS/JS, GitHub Pages) présentant les services informatiques d'Éric Allain.
Design dérivé du site EAIA (charte noir / or), avec une bannière sans liens : la navigation est
dans la barre au-dessus.

## Structure
- `index.html` — page unique « Services TI gérés pour PME » (bannières, engagements, forfaits, étapes, prix, FAQ)
- `img/` — bannières (WebP), icônes, badge
- `.nojekyll` — HTML brut

## Règles
- Aucun lien dans la bannière.
- Aucune donnée client identifiante.
- Images ≤ 500 Ko.
- Mise en ligne : validation EA obligatoire (PR vers `main`).
